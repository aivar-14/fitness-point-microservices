# Fitness Point Microservices

A Spring Boot–based microservices application for fitness and health management.

## 🚀 Project Overview
This project is built using **Spring Boot Microservices Architecture** and demonstrates:
- Service discovery using **Eureka Server**
- API routing using **Spring Cloud Gateway**
- Independent microservices for different features
- Centralized startup scripts for easy execution

## 🧩 Microservices Included
- **Eureka Server** – Service discovery
- **API Gateway** – Central entry point for APIs
- **Diet Plan Service** – Diet plan recommendations
- **Workout Service** – Workout-related APIs
- **Fitness Point Application** – Main frontend application

## 🛠 Technologies Used
- Java
- Spring Boot
- Spring Cloud (Eureka, Gateway)
- Maven
- Git & GitHub
